  What it does:

    which only has individual lesion measurements, it adds up the target
    lesions' longest diameters. It only counts a visit if every lesion measured
    at baseline was measured again.

    "BASELINE" in tr_onco and "SCREENING" in tr_onco_recist. Set baseline_visit

    including unscheduled ones.

    only the accepted reading (TRACPTFL == "Y") is used when there are two
    radiologists.

    when requested.

  How the ADaM versions work:
  - adam_waterfall_data(): takes baseline and % change directly from ADTR (the
    SDIAM parameter), and best response directly from ADRS, instead of deriving
    them. The best % change is the lowest post-baseline PCHG. Arm comes from
    TRT01A in ADSL.
  - adam_swimlane_data():
    - lanes run from TRTSDT to TRTEDT;
    - events are the per-visit responses (OVR) dated by ADT, plus deaths from
      DTHDT.
  - Configurable: the parameter codes, arm column and analysis flag are
    arguments, so studies with different conventions can still use them. Dates
    stored as text are also accepted.

  Decisions worth checking:
  - The functions only use records flagged ANL01FL == "Y" by default. I
    cross-checked the ADaM results against the SDTM derivation and found that in
    adtr_onco this flag excludes visits where not every target lesion was
    measured. Without it, subject 01-701-1118 would show -82% instead of -57.7%
    because a lesion is missing from the sum. With the flag the two routes
    agree. Flags vary between studies, so anl_flag = NULL uses all records, and
    a study without ANL01FL gets a clear error rather than silently including
    everything.
  - BOR defaults to the unconfirmed best response (bor_param = "BOR"), because
    every ADRS has it. Use bor_param = "CBOR" for confirmed response. In this
    data that changes 3 of the 6 subjects from CR to SD.
  - Some ADaM results differ from the SDTM route by design:
    - ADaM applies RECIST timing rules, so subject 1028 is PD in ADaM but SD
      with my simpler SDTM method.
    - Baseline sums differ slightly, because the ADaM derivation measures some
      lesions differently.
  - adtr_onco only has 6 subjects, so the ADaM waterfall is sparse compared with
    the SDTM example.
